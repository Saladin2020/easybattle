# Easy Battle — studio usage guide

Turn-based JRPG combat for 2D games. Agents **write `easybattle/1` JSON, check it, simulate fights and export** a
Godot 4.3+ battle scene + `Battle` autoload or a PixiJS v8 runtime. Enemy art is drawn from code (14 kinds), heroes
are Easy Sprite side-view sheets; nothing is generated by AI and nothing calls a network.

Install is local only. Do not push or modify the upstream GitHub repo.

## Paths

| What | Path |
|---|---|
| Install (package 0.1.0, `<SHA>` on master) | `/workspace/indie-studio/tools/easybattle` |
| CLI wrapper | `node /workspace/indie-studio/tools/easybattle-cli.mjs` |
| Studio projects | `/workspace/indie-studio/projects/<Name>/` |
| Format | `/workspace/indie-studio/tools/easybattle/docs/FORMAT.md` |

A game's battles live in `/workspace/indie-studio/projects/<Name>/battles/*.easybattle.json`, exports in `exports/`.
Hero sheets for custom heroes go in `sprites/<id>.png` (Easy Sprite side-view export). Ids match `^[a-z0-9_-]+$`.

## Commands

```bash
W=--workspace=/workspace/indie-studio/projects/<Name>
node …/easybattle-cli.mjs init $W
node …/easybattle-cli.mjs list enemies|heroes|skills|encounters $W [--json]
node …/easybattle-cli.mjs show nurul $W
node …/easybattle-cli.mjs check $W [--items <easyitems ws>] [--overworld <overworld.json>]   # exit 1 on errors
node …/easybattle-cli.mjs sim --party ton:5,nurul:5,mei:5 --vs cobra,wild_boar [--seed 3] [--runs 100] [--log] $W
node …/easybattle-cli.mjs encounter --region east_coast --terrain beach --times 5 $W
node …/easybattle-cli.mjs bind-overworld <overworld.json> $W
node …/easybattle-cli.mjs xp $W
node …/easybattle-cli.mjs render --what battle|bestiary --out shot.png $W
node …/easybattle-cli.mjs export --preset godot|pixi|png|json|all [--no-bundle] $W
node …/easybattle-cli.mjs serve $W                       # http://127.0.0.1:8938
```

## Godot import

Export `--preset godot`, copy `easybattle/` into the game and add `res://easybattle/easybattle.gd` as the autoload
**`Battle`**. Overworld: `var s = Battle.step(region, culture, ground_code)`; when not empty,
`Battle.start(s, $Layer, {"lang": "th"})` and `await Battle.battle_ended` (result, rewards). Rewards go into Easy
Items' `Items` autoload when present; `Battle.to_dict()` / `from_dict()` for Easy Save. Run
`godot --headless --path <export> --script res://test_battle.gd` and expect `OK`.

## Content rules

No sacred figures, scripture, Quran or Arabic calligraphy as battle content; places of worship are not battlegrounds
or enemies. Keep the cast multicultural (Thai, Malay-Muslim, Chinese-Thai).
